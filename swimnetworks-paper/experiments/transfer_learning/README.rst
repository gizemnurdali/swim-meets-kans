- This directory concerns the transfer learning tasks using the proposed sampling 
algorithm. 

- "data_paper/" directory contains all the data that was used for generating the figures 
in the main paper and the appendix. 

- "scripts_plotting/" directory contains all the scripts that can be run directly
to generate the plots in the figure and the appendix. 

- The actual experiments can be performed with the scripts in the "transfer_learning/" directory. 
The scripts contain the code for the transfer learning tasks for 3 network architectures: ResNet50,
VGG19, and Xception using two approaches: 
(1) Proposed sampling algorithm 
(2) Training with the Adam optimizer
(Information about each script is at the top of each script)
